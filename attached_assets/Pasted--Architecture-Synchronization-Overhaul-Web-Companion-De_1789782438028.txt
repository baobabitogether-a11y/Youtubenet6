# Architecture & Synchronization Overhaul: Web Companion Demo vs. Android Native Shell

This implementation plan addresses the core app goals outlined in [AGENTS.md](file:///c:/Users/User/Desktop/WORK3/youtubenet3/AGENTS.md) and the user's requirements:
1. **Platform Differentiation**: Clearly distinguish the Android Native App from the Web Companion Demo (landing page) with fixed multi-lingual artifacts and zero-overhead local testing using the default demonstration video (`FcRzAdI8R9U`).
2. **Design Re-thinking**: Elevate the UI to a premium, glassmorphic dark-mode language learning workstation, presenting an integrated dual-view (Video Player + Subtitles Teacher Panel) on the web landing page.
3. **Robust Video Play & TTS-Play Synchronization**: Fix the broken playback sync by unifying state coordination in `useSyncEngine`, eliminating the conflicting naive pause loop in `VideoPlayer.tsx`, and guaranteeing strict mutual exclusion between video dialogue and TTS narration.
4. **Accurate Subtitle Selection & Word-Boundary Highlighting**: Ensure exact cue tracking during playback and seeking, and deliver real-time word-boundary visual highlighting (`data-testid="active-tts-word-highlight"`) in `HighlightableText.tsx` during speech synthesis.

### 2. Video Play & TTS-Play Sync Engine Architecture

#### [MODIFY] [VideoPlayer.tsx](file:///c:/Users/User/Desktop/WORK3/youtubenet3/src/components/VideoPlayer.tsx)
- **Remove Conflicting Cue-Start Pause Loop**: Remove the ad-hoc `useEffect` (lines 613–730) that prematurely pauses YouTube playback at the beginning of each cue before the native speaker's dialogue is heard.
- **Speech Flow Sync Bar**: Add an interactive, docked speech-flow control bar:
  - Dual Speech Flow button: `Start Sentence Sync` / `Pause Sync`.
  - Status indicator with animated glow: `🎬 Video Playing (Russian Audio)` vs `🗣️ TTS Speaking (Target Lang)`.
  - Play Order selector: `Video Dialogue First ➔ TTS Speech` vs `TTS Speech ➔ Video Dialogue`.
  - Sentence Looping toggle: Repeats the active sentence and translation loop.
- Coordinate YouTube player pause/resume events with the sync engine using the imperative handle.

#### [MODIFY] [useSyncEngine.ts](file:///c:/Users/User/Desktop/WORK3/youtubenet3/src/hooks/useSyncEngine.ts)
- **Sentence-by-Sentence Synchronization Cycle**:
  1. **Video Segment**: Play the YouTube video for the exact cue duration (`cue.start` to `cue.start + cue.duration`). The learner listens to the native authentic speaker.
  2. **Video Pause**: Automatically pause the YouTube player as soon as the cue duration completes.
  3. **TTS Speech Narration**: Synthesize the translation in the selected target language with real-time word-boundary highlighting.
  4. **Cadence Pause & Advance**: Wait 200ms after TTS speech finishes, then resume YouTube playback for the next cue.
  5. **Looping**: If loop mode is active, seek back to `cue.start` and repeat the cycle for the current cue.
- Distinguish between automatic pauses (for TTS speech) and user pauses (spacebar/pause button), avoiding race conditions and playback freezing.
